## 調査の概要が2本ある理由

概要にあたる資料は2つあり、役割が違う。

- 厚労省の調査概要ページ（https://www.mhlw.go.jp/toukei/list/97-1a.html 、記事の2-1、2-3、2-5、2-8） … 調査全体の一般的な概要（年次に依存しない）。**記事が引用符付きで載せている調査の目的・規模の範囲・調査事項・抽出方法・目標精度・影響率の定義は、すべてこのページの文言**である。誰でも閲覧できるためassetsには置いていない
- `r7-kiso-survey-overview.pdf` … 令和7年に固有の概要。実施結果の数値（事業所数・回収率）と、年次ごとに変わる目標精度の内訳を持つ

同じ事項でも文言が異なる。抽出方法と目標精度がその例。

| | 調査概要ページ（記事の引用元） | `r7-kiso-survey-overview.pdf` |
|---|---|---|
| 母集団 | 「利用可能な最新の事業所母集団データベースにおける事業所を母集団とし」 | 「事業所母集団データベース（**令和４年次フレーム**）を母集団とし」 |
| 目標精度 | 「都道府県別、調査対象産業全体の影響率について設定し、標準誤差の最大値が**0.7％以下**」 | 「都道府県別の標準誤差を**地域別最低賃金**の審議のために調査が必要な事業所については**0.7％以内**、**特定最低賃金**の審議のために調査が必要な事業所については**1.0％以内**」 |

記事の2-8は前者を引用しており、後者にある特定最低賃金の1.0%には触れていない。飲食業・BARに特定最低賃金は設定されていないため（2-7）記事の議論には影響しないが、令和7年に固有の値としては後者のほうが詳しい。

## 記事との対応について

第1表系（表1-04〜1-06）は賃金階級が「NNNN円以下」の累積として公表されているため、記事の3-1・3-2・3-4は該当行の**公表値そのまま**である。第3表は各額の度数として公表されているため、記事の3-3は1,152円以下から目的の額までの度数を合算した**計算値**である。この区別は記事の付録Bにも記載している。

記事が参照するのは東京都シート（3-4のみ北海道シート）のみで、全国値は使っていない。
